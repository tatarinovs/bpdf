# bpdf — Быстрая и легкая утилита для работы с PDF и документами

[![Версия](https://img.shields.io/github/v/release/tatarinovs/bpdf?label=%D0%92%D0%B5%D1%80%D1%81%D0%B8%D1%8F&color=blue)](https://github.com/tatarinovs/bpdf/releases)
[![Rust](https://img.shields.io/badge/Rust-1.89%2B-orange.svg?logo=rust)](https://www.rust-lang.org/)
[![Платформа](https://img.shields.io/badge/Платформа-Windows-blue.svg?logo=windows)]()
[![Language](https://img.shields.io/badge/Language-English-blue.svg)](README.en.md)

**bpdf** — это консольный инструмент (CLI) на языке Rust для комплексной обработки PDF-файлов, изображений, текстовых документов, электронных книг и файлов Microsoft Office (Word, Excel, PowerPoint).

Утилита ориентирована на высокую скорость, низкое потребление памяти, атомарную надежность операций и удобную автоматизацию скриптов (поддержка NDJSON, списков файлов `@list.txt` и переменных окружения).

---

## Ключевые возможности

- **Универсальное объединение (`merge`):** Сборка в единый PDF документов PDF, изображений, архивов комиксов (CBZ), JPEG 2000 / JPEG-LS / JPEG XR, HEIC/AVIF/PSD, RAW-снимков камер, электронных книг (EPUB, FB2, FB2.ZIP, HTMLZ), HTML-страниц, документов Office (Word, Excel, PowerPoint, OpenDocument) и текстовых файлов.
- **Многостраничные растры и анимации:** Страницы TIFF, архивы CBZ (с естественной сортировкой) и кадры GIF/APNG/анимированного WebP раскладываются в отдельные страницы PDF при объединении.
- **Распознавание текста (OCR) и Searchable PDF:** Извлечение текста в Markdown или создание PDF с невидимым текстовым слоем (`-o searchable.pdf` / `-i`) через облачный **Groq Vision** (Qwen / Llama) или локальный автономный **Windows Media OCR** (без API-ключей и интернета).
- **Оглавление и закладки:** Автоматическое формирование дерева закладок PDF Outlines при объединении файлов (`merge --bookmarks`) с сохранением именованных ссылок.
- **Умный кеш OCR:** Content-addressed кеш на диске (хэш SHA-256 + движок/модель + промпт). Повторные запуски и параллельные задачи выполняются мгновенно без сетевых запросов.
- **Печати и штампы (`stamp`):** Наложение прозрачных PNG или JPEG штампов по координатам, привязкам (`br`, `center`), с масштабированием, прозрачностью, реалистичным смешиванием чернил (`multiply`) или интерактивным выбором места мышью в браузере (`--pick`).
- **Форматирование и приведение страниц:** Приведение к стандартам A3–A6, B4, B5, Letter, Legal, Tabloid или произвольному размеру, выравнивание ориентации по большинству страниц, сохранение исходных размеров (`keep`) или листа по размеру картинки (`fit`). Детекция и удаление пустых страниц сканов (`--remove-blank`).
- **Очистка метаданных (`strip`):** Удаление EXIF-метаданных из JPEG/PNG без перекодирования пикселей; очистка свойств, XMP и EXIF встроенных картинок внутри PDF.
- **Редактирование PDF:** Разрезание на страницы (`split`), извлечение диапазонов (`extract`), поворот (`rotate`), изменение размера страниц (`resize`), оптимизация структуры и изображений по DPI (`optimize`), подгонка под целевой размер файла (`--max-size`) и перевод графики в оттенки серого (`--gray`), шифрование AES-256 и снятие ограничений (`protect`, `unlock`).
- **Нумерация и водяные знаки:** Гибкая нумерация по шаблону (`number`) и текстовые водяные знаки (`watermark`) с автоматическим сохранением горизонтальной ориентации на повёрнутых страницах.
- **Автоповорот по EXIF:** Ориентация со смартфонов учитывается при сборке PDF, конвертации и OCR — страницы не ложатся набок.
- **Параллельная обработка:** Пакетные файлы и встроенные изображения обрабатываются параллельно на всех ядрах процессора.
- **Безопасная запись in-place:** Атомарная запись через временный файл исключает повреждение документов при сбоях.
- **Свойства документа:** Чтение структуры, шрифтов, картинок и метаданных (`info`); изменение Title, Author, Subject, Keywords, Creator (`metadata`).
- **Диагностика (`doctor`):** Проверка конфигурации, путей, системных интеграций (`ffmpeg`, `powershell`, MS Office, браузер) и доступности API Groq без расхода лимитов.
- **Меню Проводника и `bpdf-gui`:** Подменю «bpdf» в контекстном меню Windows с действиями под тип выделенных файлов, диалогами ввода параметров и окном прогресса; палитра действий `bpdf-gui.exe` для файлов, перетащенных в окно. Пункты меню настраиваются в `bpdf_shell.ini` без пересборки.
- **Интеграция с Total Commander:** Готовые панели кнопок `bpdf.bar` и `bpdf_gui.bar` (генерируются скриптами из папки `bar`), встроенные иконки под каждое действие, поддержка списков файлов `@"%UL"` и `%P%N`.

| **Облачный OCR (Groq Cloud Vision)** | Поддерживается | Поддерживается | Требуется `groq_api_key` в `config.toml` (ключ или ссылка на переменную окружения: `"%GROQ_API_KEY%"`). |

## Сборка и установка

### Сборка через Cargo

```powershell
cargo build --release
cargo test --all-targets
```

На Windows сборка не требует C/C++ компилятора (TLS — системный SChannel). На Linux/macOS для TLS используется `rustls` с бэкендом `ring`, требующим C-компилятор (`cc`/`clang`).

### Релизная сборка под Windows

Для сборки оптимизированного EXE со встроенными ресурсами Windows (иконки, манифест длинных путей UTF-8, версия):

```powershell
.\build.bat
```

Скрипт выполнит:
1. Подготовку ресурсов Windows (иконки из каталога `resources/`, генерация метаданных версии).
2. Считывание версии из `Cargo.toml`.
3. Компиляцию ресурсов через `rc.exe` (Windows SDK).
4. Оптимизированную сборку `cargo build --release --locked`.
5. Сборку расширения Проводника `bpdf_shell.dll` и `bpdf-gui.exe` (`tools\bpdf_shell\build_shell.bat`, нужен MinGW `g++` или MSVC `cl` в `PATH` либо путь к компилятору в переменной `CXX`).
6. Упаковку в директорию `dist/` и в ZIP-архив релиза:

```text
bpdf.exe, bpdf-gui.exe          утилита и графическая оболочка
config.example.toml             пример конфигурации
docs\                           README, краткая инструкция QUICKSTART.txt, LICENSE
bar\                            генераторы панелей Total Commander
shell\                          расширение Проводника, bpdf_shell.ini / bpdf_shell_en.ini,
                                register.bat, unregister.bat
```

## Глобальные флаги

Глобальные ключи указываются перед любой подкомандой:

- `--config <PATH>` — Путь к пользовательскому файлу конфигурации (по умолчанию `config.toml` рядом с `bpdf.exe`).
- `--quiet` — Тихий режим: подавляет вывод прогресса и информационных сообщений (конфликтует с `--json`).
- `--json` — Потоковый вывод событий и результатов в формате NDJSON (по одному JSON-объекту на строку).
- `--fail-fast` — Немедленная остановка пакетной команды при первой ошибке. Без флага обработка продолжается, а в конце выводится сводка ошибок.
- `--no-pause` — Не ждать нажатия Enter при выходе. Без флага `bpdf.exe`, запущенный в собственном окне консоли (из Проводника, кнопкой Total Commander), ждёт Enter, чтобы можно было прочитать вывод. То же делает переменная окружения `BPDF_NO_PAUSE`.
- `-h, --help` — Справочная информация.
- `-V, --version` — Версия программы.

## Команды и параметры

### Правила вывода и перезаписи (in-place)

Команды модификации файлов (`strip`, `rotate`, `resize`, `optimize`, `stamp`, `number`, `watermark`, `metadata`) работают по единым правилам:
- **По умолчанию (без флагов):** Рядом с исходным файлом создаётся копия вида `<имя>_<действие>.<расширение>` (`doc_stamped.pdf`, `photo_rotated.jpg`).
- `-o, --out <ФАЙЛ>` — Запись в указанный файл (только при одном входном файле).
- `-o, --out <ПАПКА>` — Запись обработанных файлов в существующую папку под исходными именами.
- `-i, --in-place` — Перезапись исходного файла на месте.

> **Безопасность записи:** Исходный файл заменяется только при явном ключе `-i` (или `--force` у `convert`). Если `-o` указывает на сам исходный файл или в одну выходную точку попадают два разных файла, операция отклоняется до начала записи. Все операции записи атомарны (через временный файл).

### 1. `bpdf merge`
Объединяет PDF, изображения, документы Office, HTML, книги и текстовые файлы в один PDF.

```powershell
bpdf merge <INPUTS>... [OPTIONS]
```

- `<INPUTS>...` — Файлы, папки, маски (`*.jpg`), диапазоны (`doc.pdf:1-5`) или манифесты (`@list.txt`).
- `-o, --out <PATH>` — Выходной файл. По умолчанию: `<имя>.pdf` (для одного файла) или `<первый>_merged.pdf`. Существующие файлы не затираются — подбирается свободный суффикс (`_merged_2.pdf`).
- `-s, --size <SIZE>` — Размер страниц: `A3`–`A6`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`, произвольный `ШИРИНАxВЫСОТА` (`210x297mm`, `8.5x11in`), `keep` (сохранять размеры страниц PDF) или `fit` (страница под размер картинки по её DPI, иначе 96 DPI). По умолчанию берётся `page_size` из конфигурации.
- `--auto-rotate` / `--no-auto-rotate` — Выравнивать ориентацию страниц по большинству.
- `--optimize` / `--no-optimize` — Уменьшать картинки до `image_dpi` и сжимать структуру.
- `--strip-meta` / `--no-strip-meta` — Удалять метаданные из итогового документа.
- `--bookmarks` / `--no-bookmarks` — Создавать закладку (Outline) на каждый объединяемый файл.
- `--max-size <SIZE>` — Ограничение размера файла (`10MB`, `500KB`): разрешение и качество графики ступенчато понижаются до выполнения условия.
- `--remove-blank` — Удалять пустые страницы сканов (чистые листы без текста).

---

### 2. `bpdf ocr`
Распознает сканы и изображения через облачный Groq Vision или локальный Windows OCR. Страницы PDF с готовым текстом не расходуют трафик и берутся как есть.

```powershell
bpdf ocr <INPUTS>... [OPTIONS]
```

- `-o, --out <PATH>`:
  - `.pdf` — создание **Searchable PDF** с невидимым текстовым слоем;
  - `.md` (или другое расширение) — единый текстовый Markdown-файл;
  - без `-o` — создаются индивидуальные `.md` рядом с каждым входным файлом.
- `-i, --in-place` — Добавить текстовый слой прямо в исходные PDF (диапазон `doc.pdf:2-4` ограничит распознавание выбранными страницами); изображение становится поисковым `ИМЯ.pdf` рядом с ним (занятое имя — `ИМЯ_2.pdf`).
- `-e, --engine <ENGINE>` — Движок: `groq`, `windows` или `auto` (по умолчанию `ocr_engine`). В режиме `auto` при сетевых проблемах или отказе API-ключа Groq происходит автоматический переход на Windows OCR.
- `--lang <LANG>` — Языковой профиль Windows OCR (`ru`, `en-US`; по умолчанию `ocr_lang`).
- `--force-ocr` — Принудительно распознавать даже те страницы, где уже есть текстовый слой.
- `--no-cache` — Игнорировать дисковый кеш OCR.
- `--clear-cache` — Очистить дисковый кеш OCR.

---

### 3. `bpdf split`
Разбивает PDF на отдельные страницы `<имя>_01.pdf`, `<имя>_02.pdf`, …

```powershell
bpdf split <INPUT> [-o <DIR>] [--force]
```

- `-o, --out <DIR>` — Папка назначения (по умолчанию папка исходного файла).
- `--force` — Разрешить перезапись уже существующих файлов страниц.

---

### 4. `bpdf extract`
Извлекает выбранные страницы в новый PDF с сохранением порядка и повторов.

```powershell
bpdf extract <INPUT> <PAGES> [-o <OUT> | -i]
```

- `<PAGES>` — Выборка страниц: `1-5`, `5,1-4`, `odd`, `even`, `reverse` (подробнее в разделе [Синтаксис страниц](#синтаксис-диапазонов-страниц)).

---

### 5. `bpdf info`
Выводит детальную информацию о PDF: версию стандарта, размеры страниц (pt и мм), повороты, количество шрифтов и картинок на каждой странице, а также метаданные документа.

```powershell
bpdf info <INPUT>
```

---

### 6. `bpdf text`
Быстрое извлечение существующего текстового слоя из PDF без обращения к сети.

```powershell
bpdf text <INPUT> [-o <OUT>]
```

Без `-o` текст выводится в стандартный поток (stdout).

---

### 7. `bpdf strip`
Удаляет метаданные из JPEG, PNG и PDF без перекодирования пикселей.

```powershell
bpdf strip <INPUTS>... [-o <OUT> | -i]
```

В PDF очищаются свойства документа, XMP-пакеты, личные данные приложений и EXIF/XMP встроенных изображений. Профили ICC сохраняются, если включено `keep_icc = true`.

---

### 8. `bpdf rotate`
Поворачивает страницы PDF или файлы JPEG на угол, кратный 90°, либо к заданной ориентации.

```powershell
bpdf rotate <INPUTS>... -a <ANGLE> [-p <PAGES>] [-o <OUT> | -i]
```

- `-a, --angle <ANGLE>` — Поворот: `90`, `180`, `270`, `-90` или целевая ориентация `portrait` / `landscape`.
- `-p, --pages <PAGES>` — Страницы для PDF (по умолчанию `all`).

> JPEG поворачивается **без потерь качества** (через обновление тега ориентации EXIF без декомпрессии пикселей).

---

### 9. `bpdf resize`
Масштабирует и центрирует страницы PDF на выбранный лист или изменяет размер JPEG.

```powershell
bpdf resize <INPUTS>... [-s <SIZE>] [--long-edge <PX>] [--short-edge <PX>] [-p <PAGES>] [-o <OUT> | -i]
```

- `-s, --size <SIZE>` — Формат листа для PDF (по умолчанию `A4`). Аннотации и ссылки автоматически сдвигаются вместе с контентом.
- `--long-edge <PX>` / `--short-edge <PX>` — Ограничение длинной или короткой стороны для JPEG.

---

### 10. `bpdf optimize`
Сжимает структуру PDF и уменьшает встроенные изображения до `image_dpi` с качеством `jpeg_quality`.

```powershell
bpdf optimize <INPUT> [--max-size <SIZE>] [--gray] [--remove-blank] [-o <OUT> | -i]
```

- `--max-size <SIZE>` — Подогнать под размер (`10MB`, `500KB`).
- `--gray` — Перевести цветные растры в оттенки серого (текст и вектор сохраняют цвета).
- `--remove-blank` — Удалить пустые страницы сканов (страницы без текста, содержащие только фоновый шум бумаги).

---

### 11. `bpdf stamp`
Накладывает штамп или печать (прозрачный PNG или JPEG) поверх страниц PDF.

```powershell
bpdf stamp <INPUT> <STAMP> [OPTIONS]
```

- `--position <POS>` — Якорные точки (`br`, `bl`, `tr`, `tl`, `c`, `tc`, `bc`, `l`, `r`) или смещение `X,Y` в мм от правого нижнего угла (по умолчанию `br`).
- `--scale <SCALE>` — Масштаб (по умолчанию физический размер; `0` — вписать в четверть страницы).
- `--dpi <DPI>` — Разрешение штампа (по умолчанию из файла, иначе 96).
- `--opacity <0-1>` — Непрозрачность (по умолчанию `1.0`).
- `--blend <MODE>` — Режим смешивания: `normal`, `multiply` (эффект чернил на бумаге), `screen`, `overlay` и др.
- `-p, --pages <PAGES>` — Страницы (по умолчанию `all`).
- `--pick` — Интерактивный визуальный выбор позиции мышью в окне браузера с предпросмотром.

---

### 12. `bpdf number`
Добавляет нумерацию страниц по шаблону с сохранением горизонтального положения текста на повёрнутых страницах.

```powershell
bpdf number <INPUT> [OPTIONS]
```

- `--format <TEXT>` — Шаблон: `{n}` — текущий номер, `{total}` — всего страниц (по умолчанию `{n}`).
- `--start <N>` — Начальный номер (по умолчанию `1`).
- `--position <POS>` — Позиция (по умолчанию `bc` — внизу по центру).
- `--size <PT>` — Размер шрифта (по умолчанию `10`).
- `--color <COLOR>` — Цвет: `black`, `gray`, `red`, `blue`, `green`, `white` или `#RRGGBB`.
- `--opacity <0-1>` — Непрозрачность (по умолчанию `1.0`).
- `-p, --pages <PAGES>` — Целевые страницы (например, `2-last`, чтобы пропустить обложку).

---

### 13. `bpdf watermark`
Накладывает текстовый водяной знак поверх страниц.

```powershell
bpdf watermark <INPUT> <TEXT> [OPTIONS]
```

- `--size <PT>` — Размер шрифта (`0` — автоподбор под диагональ страницы).
- `--angle <DEG>` — Угол наклона в градусах против часовой стрелки (по умолчанию `45`).
- `--position <POS>` — Положение (по умолчанию `c` — центр).
- `--color <COLOR>` — Цвет (по умолчанию `gray`).
- `--opacity <0-1>` — Непрозрачность (по умолчанию `0.3`).

### 14. `bpdf metadata`
Управляет метаданными документа (неуказанные поля сохраняются, передача пустого значения удаляет поле).

```powershell
bpdf metadata <INPUT> [--title ..] [--author ..] [--subject ..] [--keywords ..] [--creator ..] [-o <OUT> | -i]
```

### 15. `bpdf protect` и `bpdf unlock`
Управление шифрованием AES-256 (стандарт PDF 2.0).

```powershell
bpdf protect <INPUT> [--password <PW>] [--owner-password <PW>] [--no-print] [--no-copy] [--no-modify] [-o <OUT> | -i]
bpdf unlock <INPUT> [--password <PW>] [-o <OUT> | -i]
```

- `--password` — Пароль на открытие документа.
- `--owner-password` — Пароль владельца для снятия ограничений.
- `--no-print`, `--no-copy`, `--no-modify` — Запрет печати, копирования содержимого и редактирования.

Пароли можно передать через окружение, чтобы они не попадали в командную строку: `BPDF_PROTECT_PASSWORD` и `BPDF_PROTECT_OWNER_PASSWORD` для `protect`, `BPDF_UNLOCK_PASSWORD` для `unlock` (так делает `bpdf-gui` для `{ask_pass:...}`). У каждой команды свои переменные, поэтому пароль для `unlock` никогда не зашифрует файл.

Запреты PDF — это договорённость с программами просмотра, а не защита содержимого: `unlock` снимает их без пароля владельца, а `merge` собирает новый документ без ограничений исходников. `split` и команды правки (`rotate`, `stamp` и др.) сохраняют защиту файла.

---

### 16. `bpdf convert`
Экспорт изображений, страниц PDF, HTML и SVG в формат JPEG.

```powershell
bpdf convert <INPUTS>... [OPTIONS]
```

- `-o, --out <DIR>` — Папка для сохранения JPEG.
- `--render` — Полный рендеринг страниц PDF (вместо извлечения встроенных растровых изображений).
- `--long-edge <PX>` / `--short-edge <PX>` — Масштабирование по длинной/короткой стороне.
- `--orient <MODE>` — Принудительная ориентация (`landscape` или `portrait`).
- `-q, --quality <1-100>` — Качество сжатия JPEG (по умолчанию `jpeg_quality`).
- `--max-size <SIZE>` — Подгонка веса каждого JPEG (например, `500KB`).
- `--viewport <WxH>` — Размер окна браузера для рендеринга HTML (по умолчанию `1200x1600`).
- `--force` — Перезапись существующих файлов.

Диагностика окружения: проверка файла конфигурации, доступности внешних утилит (FFmpeg, PowerShell, MS Office, браузер) и проверка связи с API Groq без расхода квот.

```powershell
bpdf doctor
```

## Форматы входа и синтаксис страниц

### Синтаксис диапазонов страниц
Используется в ключе `-p, --pages`, команде `extract` и непосредственно в путях входных файлов (`doc.pdf:1-3`):
- `all` — все страницы;
- `first` — первая страница;
- `last` (или `l`) — последняя страница;
- `even` / `odd` — только четные / нечетные страницы;
- `reverse` — обратный порядок страниц;
- Комбинации и диапазоны: `1-5,8,last`, `2-last`, `5-` (с 5-й до конца), `5-1` (в обратном порядке).

```powershell
bpdf merge scan.jpg report.pdf:1-3,last notes.txt -o result.pdf
```

### Списки файлов (манифесты `@list.txt`)
Передавайте список файлов в текстовом документе с префиксом `@`:

```powershell
bpdf merge @files.txt -o output.pdf
```

Пример содержимого `files.txt`:
```text
# Комментарии игнорируются
C:\docs\cover.jpg
C:\docs\report.pdf:1-10
C:\docs\appendix.pdf:even
```

### Шаблоны (Globs)
Маски путей (`*.jpg`, `scans/*.pdf`) автоматически раскрываются с естественной сортировкой чисел в именах файлов (`scan_1.jpg`, `scan_2.jpg`, `scan_10.jpg`).

### Меню Проводника Windows
1. Распакуйте архив в постоянное место (например, `C:\Tools\bpdf\`): расширение ищет `bpdf.exe` и `bpdf-gui.exe` рядом с собой, в папке выше или в `PATH`.
2. Запустите `shell\register.bat`. Регистрация идёт в разделе текущего пользователя (`HKCU`), права администратора не нужны. Удаление — `shell\unregister.bat`.
3. В контекстном меню файлов и папок появится подменю «bpdf». В Windows 11 оно находится в классическом меню: *Показать дополнительные параметры* или `Shift+F10`.

Набор пунктов зависит от выделения: один PDF, одно изображение, одна папка, другой файл или несколько файлов (разделы `[menu.single.pdf]`, `[menu.single.image]`, `[menu.single.directory]`, `[menu.single.default]`, `[menu.multi]` в `shell\bpdf_shell.ini`). Формат пунктов и подстановки описаны в начале файла; изменения применяются сразу после сохранения. Английский набор пунктов лежит рядом в `bpdf_shell_en.ini`: чтобы им пользоваться, скопируйте его поверх `bpdf_shell.ini`.

Пункт меню запускает `bpdf-gui.exe`. Он показывает диалоги для параметров `{ask:...}` (угол, формат, текст) и `{ask_pass:...}` (пароль вводится со звёздочками и передаётся `bpdf` через окружение), затем окно прогресса. На быстрых задачах окно не появляется вовсе; при ошибке или предупреждениях оно остаётся открытым.

### Палитра действий `bpdf-gui`
`bpdf-gui.exe` без команды открывает палитру: те же действия из `bpdf_shell.ini` для переданных файлов, перетащенных в окно или выбранных кнопкой «Выбрать файлы...». С командой после `--` он выполняет её с окном прогресса и диалогами:

```powershell
bpdf-gui.exe scan.pdf                                         # палитра для файла
bpdf-gui.exe --icon 7 -- rotate doc.pdf -a "{ask:Угол:90}" -i  # команда с диалогом
bpdf-gui.exe --gui keep -- doctor                             # окно не закрывается
```

Опции: `--title <текст>`, `--icon <номер>` (иконка из ресурсов `bpdf.exe`), `--gui auto|info|keep`, `--item <номер>` (пункт палитры), `--cmd "команда"`. Справка — `bpdf-gui.exe --help`.

### Интеграция с Total Commander
1. Скопируйте утилиту в каталог инструментов (например, `%COMMANDER_PATH%\tools\bpdf\`).
2. Запустите один из генераторов в папке `bar` — он создаст рядом с собой файл панели с путями относительно `%COMMANDER_PATH%`:
   - `make_bar.bat` → `bpdf.bar`: кнопки вызывают `bpdf.exe` в окне консоли;
   - `make_bar_gui.bat` → `bpdf_gui.bar`: кнопки вызывают `bpdf-gui.exe` с окном прогресса, диалогами параметров и палитрой действий на первой кнопке;
   - `make_bar_en.bat`, `make_bar_gui_en.bat` — то же с английскими подписями (`bpdf_en.bar`, `bpdf_gui_en.bar`).
3. Перетащите `.bar` на панель Total Commander или подключите через *Конфигурация → Панель инструментов*.
4. Доступны кнопки под все ключевые операции со встроенными иконками и поддержкой списков выделенных файлов `@"%UL"`.

С ключом `/default` генераторы пишут путь `%COMMANDER_PATH%\tools\bpdf` без поиска установленного `bpdf.exe` (для сборок Total Commander).

## Конфигурация (`config.toml`)

Файл настроек ищется в следующем порядке:
1. Путь, переданный в параметре `--config <PATH>`.
2. Файл `config.toml`, расположенный рядом с `bpdf.exe`.

В строковых значениях поддерживается автоматическое раскрытие системных переменных окружения вида `%NAME%`.

### Пример `config.toml`

```toml
# API-ключ Groq для Vision OCR (раскрывается из переменной окружения)
groq_api_key = "%GROQ_API_KEY%"

# Прокси-сервер (HTTP или SOCKS5)
proxy = ""
# proxy = "socks5://127.0.0.1:10808"

# Метаданные по умолчанию для новых PDF
author = "My Company"
creator = "bpdf toolkit"

# Параметры обработки PDF
auto_rotate = false
keep_icc = false
optimize = false
strip_metadata = false
bookmarks = false
page_size = "A4"
jpeg_quality = 95
image_dpi = 150
raw_develop = false # false = быстрое Pure-Rust превью, true = проявка WIC

# Настройки OCR
ocr_engine = "groq" # "groq", "windows" или "auto"
ocr_model = "qwen/qwen3.8-27b"
ocr_endpoint = "https://api.groq.com/openai/v1/chat/completions"
ocr_jobs = 1
ocr_cache = true
# ocr_cache_dir = 'D:\cache\bpdf-ocr'
ocr_timeout_seconds = 120
ocr_max_tokens = 4096

# Внешние утилиты и интеграции
ffmpeg = 'ffmpeg'
powershell = 'powershell.exe'
# font_path = '%WINDIR%\Fonts\arial.ttf'
office_timeout_seconds = 120
# browser = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
html_timeout_seconds = 60
html_viewport = "1200x1600"
```

Полный образец со всеми комментариями находится в файле [`config.example.toml`](config.example.toml).

## Примеры использования

### Сборка и конвертация в PDF
```powershell
# Собрать картинки, страницы отчета и заметки в один PDF
bpdf merge scan.jpg invoice.pdf:1-3 notes.txt -o result.pdf

# Объединить все JPG из папки с приведением к A4, автоповоротом и сжатием
bpdf merge *.jpg -s A4 --auto-rotate --optimize -o scans.pdf

# Собрать электронные книги и документы Office в PDF
bpdf merge book.epub presentation.pptx table.xlsx -o bundle.pdf

# Сохранить веб-страницу в PDF через браузер Edge/Chrome
bpdf merge page.html -o page.pdf
```

### Распознавание текста (OCR)
```powershell
# Распознать скан через Groq Vision в Markdown
bpdf ocr scan.jpg -o scan.md

# Добавить невидимый текстовый слой в исходные сканы локальным Windows OCR
bpdf ocr scans/*.pdf -e windows -i

# Создать Searchable PDF из многостраничного документа
bpdf ocr document.pdf -o document_searchable.pdf

# Извлечь уже существующий текстовый слой без сети
bpdf text document.pdf -o extracted_text.txt
```

### Редактирование и геометрия страниц
```powershell
# Разбить PDF на отдельные страницы
bpdf split document.pdf -o pages/

# Извлечь первые 5 страниц и последнюю страницу
bpdf extract document.pdf 1-5,last -o summary.pdf

# Повернуть все четные страницы PDF на 90 градусов на месте
bpdf rotate document.pdf -a 90 -p even -i

# Подогнать страницы под формат Letter с центрированием
bpdf resize document.pdf --size Letter
```

### Оптимизация, штампы и оформление
```powershell
# Оптимизировать PDF с подгонкой под целевой размер файла
bpdf optimize document.pdf --max-size 5MB --remove-blank -i

# Поставить печать в правый нижний угол с эффектом чернил (multiply)
bpdf stamp contract.pdf seal.png --blend multiply -i

# Интерактивное позиционирование печати мышью в окне браузера
bpdf stamp contract.pdf seal.png --pick --blend multiply -i

# Пронумеровать страницы с пропуском титульного листа
bpdf number report.pdf -p 2-last --format "Стр. {n} из {total}" -i

# Наложить водяной знак "КОПИЯ" полупрозрачным красным цветом
bpdf watermark contract.pdf "КОПИЯ" --color red --opacity 0.25 -i
```

### Метаданные, защита и экспорт
```powershell
# Очистить метаданные и EXIF у всех фото в папке на месте
bpdf strip photos/*.jpg -i

# Задать заголовок и автора документа
bpdf metadata doc.pdf --title "Отчет 2026" --author "Иван Иванов" -i

# Защитить PDF паролем с запретом печати и копирования
bpdf protect doc.pdf --password "secret123" --no-print --no-copy -i

# Снять пароль и ограничения
bpdf unlock doc.pdf --password "secret123" -i

# Экспортировать страницы PDF и HTML в JPEG-изображения
bpdf convert doc.pdf page.html --out converted_images/
```
